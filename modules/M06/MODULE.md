# M06 容器原理

参考周期：4 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

Linux 资源和网络基础；本地容器运行时。

## 必学内容

 Namespace、cgroup v2、OCI、OverlayFS、容器网络、资源限制。

## 输出 / 交付物

容器运行原理图、CPU/内存隔离实验。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：在本地容器比较隔离前后资源观测，记录配额与内存上限触发后的恢复。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能说明容器与宿主机的关系，复现 CPU 限流与 OOM。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
