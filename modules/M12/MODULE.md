# M12 故障响应与复盘

参考周期：5 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M11 告警与仪表盘；演练伙伴或预设盲测场景。

## 必学内容

事故分级、On-call、止损、应急指挥、时间线、Postmortem。

## 输出 / 交付物

3份完整事故演练记录、Runbook、行动项清单。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：安排三次盲测，记录影响、分工、止损、恢复与行动项复验。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

面对未知故障能控制影响、恢复服务、分析原因并验证改进。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
