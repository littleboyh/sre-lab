# M04 Linux 网络

参考周期：6 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

Linux 基线；本地测试服务与客户端。

## 必学内容

TCP/IP、DNS、Socket、连接队列、重传、拥塞控制、NAT、conntrack、抓包。

## 输出 / 交付物

网络故障实验、pcap、网络排查SOP。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：在本地拓扑逐一改变 DNS、监听状态和链路质量；结合客户端时间线与抓包验证。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

独立定位 DNS、连接失败、丢包或重传等网络问题。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
