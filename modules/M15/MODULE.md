# M15 安全与平台治理

参考周期：4 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M07、M13；隔离集群与测试身份。

## 必学内容

 RBAC、NetworkPolicy、TLS、Secret、镜像安全、配置审计。

## 输出 / 交付物

威胁模型、安全基线、最小权限规范。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：用测试身份验证允许和拒绝的访问矩阵；核对审计记录并复测合法操作。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

未授权访问被阻断，配置可审计，修复措施可验证。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
