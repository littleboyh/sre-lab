# M00 学习系统与实验环境

参考周期：2 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

Windows + WSL2 或可重建的 Linux 虚拟机；Git；本地隔离环境。

## 必学内容

实验隔离、环境管理、系统基线、文档规范。

## 输出 / 交付物

实验环境、Git 仓库、环境基线、实验模板。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [x] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [x] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [x] 在隔离环境完成实验：记录环境版本和基线；从干净快照按文档重建并比对结果。
- [x] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能重新搭建环境、执行基线采集、可靠恢复初始状态。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
