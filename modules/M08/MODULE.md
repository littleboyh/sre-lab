# M08 分布式系统

参考周期：7 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M05、M07；可丢弃的中间件实例和测试数据。

## 必学内容

一致性、复制、选主、幂等、超时、重试、背压，以及 Kafka、Redis、PostgreSQL、ClickHouse、对象存储。

## 输出 / 交付物

一条可靠数据处理流水线、系统依赖图、故障注入报告。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：给测试流水线提交可计数事件；暂停消费者并重放，核对重复、缺失及积压恢复。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

解释数据重复、丢失、延迟和一致性问题，并证明恢复机制有效。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
