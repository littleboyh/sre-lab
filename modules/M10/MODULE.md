# M10 OpenTelemetry 工程

参考周期：6 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M09；两个可互相调用的测试服务。

## 必学内容

 API/SDK、Context、Propagation、OTLP、Collector、采样、队列、重试、WAL、背压。

## 输出 / 交付物

多服务 Trace、Collector 管线、可靠性实验报告。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：暂停测试遥测后端，观察队列与数据丢失；恢复后核对发送、接收与丢弃计数。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

下游持续失败时，能量化队列、内存、重试和丢数据边界。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
