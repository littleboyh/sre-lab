# M05 编程与工程诊断

参考周期：5 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M00～M04 实验；Go 与 Shell 开发环境。

## 必学内容

 Go、Shell、Git、单元测试、并发、pprof、自动化。

## 输出 / 交付物

一个带故障开关的 Go 服务、测试脚本、性能分析报告。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：加入可关闭的慢路径，对照基准与 profile；修复后用测试证明改动。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能修改程序、构建测试、定位其性能问题并自动验证。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
