# M14 容量、性能与容灾

参考周期：6 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M09～M13；历史负载与可恢复备份。

## 必学内容

排队理论、容量预测、压测、性能优化、备份与恢复、RTO/RPO。

## 输出 / 交付物

容量评估、性能报告、备份恢复演练。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：逐档提高负载以测量容量拐点；从测试备份恢复并核对 RTO、RPO。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能计算安全容量并实测恢复时间与数据损失窗口。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
