# M13 发布与自动化工程

参考周期：5 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M07；Git、部署清单和健康检查。

## 必学内容

 CI/CD、IaC、Ansible/Terraform、GitOps、灰度发布、回滚。

## 输出 / 交付物

完整部署流水线、变更控制、回滚演练。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：部署一个健康检查失败的测试版本，验证停止放量、回滚和版本追溯。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

从代码提交到部署可追溯，错误版本可安全回滚。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
