# M09 可观测性基础设施

参考周期：6 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M07；Go 服务及可控请求流量。

## 必学内容

 USE/RED、Metrics、Histogram、Prometheus、VictoriaMetrics、Grafana、日志、Traces。

## 输出 / 交付物

完整监控看板、指标规范、基础告警。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：生成稳定与退化两组流量，交叉验证看板、日志与追踪，并记录标签基数变化。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能用可观测数据证明服务状态，避免高基数问题，准确识别性能退化。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
