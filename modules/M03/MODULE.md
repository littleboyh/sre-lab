# M03 存储与 I/O

参考周期：5 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M00 基线；独立测试卷与可丢弃数据。

## 必学内容

VFS、文件系统、inode、fd、fsync、Writeback、块设备、磁盘延迟与队列。

## 输出 / 交付物

fio 测试报告、I/O分析报告、恢复脚本。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：在测试卷固定数据量，逐个改变块大小、并发和同步写；比较吞吐与尾延迟。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能判断磁盘空间、FD、IOPS、吞吐或延迟瓶颈。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
