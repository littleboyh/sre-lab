# M16 综合架构与专家级实战

参考周期：8 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M00～M15；综合项目、部署记录与运行数据。

## 必学内容

架构取舍、端到端压测、故障演练、恢复与技术评审。

## 输出 / 交付物

架构设计、SLO、容量评估、部署回滚、演练报告与运维文档。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：第三方从零部署；运行负载和依赖退化演练；评审架构并追踪改进。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

从零部署与恢复可复现；量化高并发及依赖故障边界；独立盲测；由他人按文档接手。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
