# M02 内存与内核资源

参考周期：5 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M00 基线与 M01 资源诊断方法；受限实验环境。

## 必学内容

虚拟内存、页表、Page Cache、Swap、Slab、OOM、PSI、cgroup。

## 输出 / 交付物

内存实验、OOM证据、内存诊断手册。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：在隔离环境对比缓存增长、进程持续分配与受限容器 OOM；恢复后复测。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

区分内存泄漏、缓存增长、容器内存受限，解释证据。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
