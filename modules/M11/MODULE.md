# M11 SLO与告警工程

参考周期：5 周 · 每周 6～8 小时。状态以 [进度总账](../../PROGRESS.md) 为准。

## 输入 / 前提

M09～M10；可重放的请求计数数据。

## 必学内容

 SLI、SLO、错误预算、Burn Rate、多窗口告警。

## 输出 / 交付物

SLO文档、错误预算看板、告警规则。记录版本与证据链接，确保能再次运行。

## 学习与实验任务

- [ ] 从 [周计划](../../templates/WEEKLY_PLAN.md) 拆出本模块的周目标。
- [ ] 用 [原理笔记](../../templates/THEORY.md) 写下机制、预测与适用边界。
- [ ] 在隔离环境完成实验：重放短时尖峰、持续退化和无流量样本，验证错误预算及告警触发和恢复。
- [ ] 对照实验前后指标，保存数据并记录恢复验证。
- [ ] 整理交付物与可复用排查步骤；安排独立验收。

## 必过的模块验收

能计算服务可靠性、解释预算消耗，并验证告警是否有效。验收者只给现象和目标；记录假设、排除依据、操作与恢复证据。按 [统一验收标准](../../ASSESSMENT.md) 评分，将 [验收结果](../../templates/ASSESSMENT_RESULT.md) 存入 `assessment/RESULT.md`，再更新总账。
